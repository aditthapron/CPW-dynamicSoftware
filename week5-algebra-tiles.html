✖️ คูณพหุนามด้วยแผ่น (บวก/ลบ)

ศึกษาการคูณของพหุนาม (ax + b)(cx + d) โดยการสังเกตพื้นที่ของสี่เหลี่ยม (แผ่นสีแดงหมายถึงค่าลบ)

ปรับขนาดตัวคูณ (ค่าลบจะเปลี่ยนเป็นสีแดง):
แนวตั้ง (สูง): 1x + 2
แนวนอน (กว้าง): 1x + 3
โหมดกระดาน:
💡 ลองลากแผ่น x², x และ 1 จากแถบเครื่องมือซ้ายมือ มาวางจัดเรียงลงบนกระดานให้ตรงกับวงเล็บกว้าง × สูง!
สมการผลคูณพหุนาม:
(x + 2)(x + 3) = x² + 5x + 6
คำนวณแบบไม่ใช้แผ่น (ตารางคูณไขว้ - Box Method)
🧮 แบบทดสอบการคูณพหุนาม

หาผลคูณของพหุนาม แล้วพิมพ์คำตอบในรูป x² + bx + c
ข้อ 1-5 กระดานแสดงแผ่นพื้นที่ช่วยนับ · ข้อ 6-10 ต้องคิดเอง ไม่มีแผ่นช่วย

จงหาผลคูณของพหุนามต่อไปนี้:
(x + 2)(x + 3)
เคล็ดลับ: ผลคูณ = พื้นที่รวม (กว้าง × ยาว) รวมแผ่น x², x และ 1 ทั้งหมด
ความก้าวหน้า: 0 / 10 ข้อ
🔢 หาคู่จำนวน: คูณกันได้ · บวกกันได้
ทำไมต้องฝึกเรื่องนี้?
เมื่อคูณ (x + p)(x + q) จะได้ x² + (p + q)x + (p × q)
• ตัวเลขกลาง (สัมประสิทธิ์ของ x) = ผลบวก p + q
• ตัวเลขท้าย (ค่าคงที่) = ผลคูณ p × q
ถ้าเราหา “สองจำนวนที่คูณกันได้ค่าท้าย และบวกกันได้ค่ากลาง” ได้ ก็พร้อมสำหรับการแยกตัวประกอบในสัปดาห์หน้า!
วิธีคิดด้วยการแตกตัวประกอบ (ห.ร.ม.):
1) แตกค่าท้าย (C) ออกเป็นคู่ตัวประกอบทั้งหมด
2) เลือกคู่ที่บวกกันได้ค่ากลาง (B)
ตัวอย่าง: C = 12 → 1×12, 2×6, 3×4 · ถ้า B = 7 ตอบ 3 กับ 4
หาสองจำนวนบวกที่...
คูณกันได้ 12
และบวกกันได้ 7
