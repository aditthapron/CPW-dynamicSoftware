🔢 หาคู่จำนวน: คูณกันได้ · บวกกันได้
ทำไมต้องฝึกเรื่องนี้?
เมื่อแยกตัวประกอบ x² + Bx + C เป็น (x + p)(x + q) ต้องหา 2 จำนวนที่
• คูณกันได้ C (ค่าคงที่)
• บวกกันได้ B (สัมประสิทธิ์ของ x)
ถ้า C เป็นลบ แสดงว่าจำนวนสองตัวมีเครื่องหมายต่างกัน (บวกหนึ่ง ลบหนึ่ง)!
วิธีคิด:
1) แตกค่าท้าย (C) ออกเป็นคู่ตัวประกอบทั้งหมด (รวมทั้งคู่ที่มีค่าลบถ้า C เป็นลบ)
2) เลือกคู่ที่บวกกันได้ค่ากลาง (B)
ตัวอย่าง: C = -6 → 1×-6, -1×6, 2×-3, -2×3 · ถ้า B = -1 ตอบ 2 กับ -3

🧩 แยกตัวประกอบพหุนาม

หาตัวประกอบของพหุนาม x² + Bx + C โดยการจัดขนาดสี่เหลี่ยมผืนผ้าให้ได้พื้นที่ที่กำหนดพอดี
ข้อ 1-5 เปิดแผ่นเฉลยช่วยดูได้ · ข้อ 6-10 ต้องฝึกแยกเอง ไม่มีแผ่นเฉลย

โจทย์พหุนามเป้าหมาย:
x² + 5x + 6
ต้องการแผ่น: 🟦 x² = 1 แผ่น · ·
💡 ใบ้: หา p และ q ที่
ปรับขนาดด้านของสี่เหลี่ยมเพื่อแยกตัวประกอบ:
ด้านสูง (x + p): 1x + 1
ด้านกว้าง (x + q): 1x + 1
โหมดกระดาน:
💡 ลากแผ่นตามจำนวนที่ระบุลงบอร์ด แล้วทดลองต่อเป็นสี่เหลี่ยมด้วยตัวเอง!
